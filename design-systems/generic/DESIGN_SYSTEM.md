# Generic wireframe kit

Use plain semantic HTML and only these classes: `wf-page` › `wf-header` + `wf-body` › `wf-sidebar` + `wf-main`;
`wf-row`/`wf-col` for grids; `wf-card`; `wf-heading`, `wf-text`; `wf-btn`, `wf-btn wf-btn-primary`; `wf-input`;
`table.wf-table`; `wf-note` for annotations.
